JavaScript Fundamentals

Scope

Understand where variables and functions are accessible in JavaScript and how global, function, block and lexical scope control variable visibility.

Beginner Variables Interview Essential
Definition Syntax Types Lexical Scope Examples Real Life Interview Challenge
01

Foundation

What is scope?

?

What?

Scope determines where a variable, function or other identifier can be accessed in a JavaScript program.

⏱

When?

Scope matters whenever you create variables, functions, blocks or nested code and need to understand which identifiers are available in a particular location.

💡

Why?

Scope prevents unnecessary access to variables, reduces naming conflicts and helps keep application code organized and predictable.

⚙

How?

JavaScript determines variable accessibility based on where the variable is declared and the surrounding lexical structure of the code.

02

Fundamentals

Scope syntax

JavaScript 
// Global scope

let globalValue = 100;

function example() {

    // Function scope

    let functionValue = 200;

    if (true) {

        // Block scope

        let blockValue = 300;

    }

}
Remember: A variable declared inside a scope is generally available to that scope and its nested scopes, but not to its outer scopes.
03

Core concepts

Types of scope

Type 01

Global Scope

A variable declared outside functions and blocks is available from the global scope, subject to JavaScript's environment-specific global rules.

JavaScript 
const appName = "JavaScript Playground";

function showAppName() {

    console.log(appName);

}

showAppName();

// JavaScript Playground
Type 02

Function Scope

Variables declared with var inside a function are scoped to that function.

JavaScript 
function calculate() {

    var result = 100;

    console.log(result);

}

calculate();

// 100

// console.log(result);
// ReferenceError
Type 03

Block Scope

Variables declared with let and const are block-scoped. A block is created by curly braces such as those used by if, for and while.

JavaScript 
if (true) {

    let message = "Inside block";

    const number = 10;

    console.log(message);
    console.log(number);

}

// console.log(message);
// ReferenceError

// console.log(number);
// ReferenceError
Type 04

Module Scope

Variables declared at the top level of an ES module belong to that module and are not automatically global. Modules can explicitly share values using export and import.

JavaScript 
// math.js

const taxRate = 18;

export function calculateTax(price) {

    return price * taxRate / 100;

}


// app.js

import { calculateTax } from "./math.js";

console.log(calculateTax(1000));
// 180
04

Important concept

Lexical scope

Core Idea

Inner scopes can access outer scopes

JavaScript uses lexical scoping. This means the accessibility of a variable is determined by where the code is written, not by where the function is eventually called.

JavaScript 
const outer = "I am outside";

function outerFunction() {

    const inner = "I am inside";

    function innerFunction() {

        console.log(outer);
        console.log(inner);

    }

    innerFunction();

}

outerFunction();

// I am outside
// I am inside
💡

Think of scope like nested rooms: an inner room can access things from the rooms outside it, but an outer room cannot directly access private things inside the inner room.

05

Interview essential

var vs let vs const

Comparison

Scope behavior

Understanding the scope differences between var, let and const is one of the most common JavaScript interview topics.

JavaScript 
if (true) {

    var a = 10;
    let b = 20;
    const c = 30;

}

console.log(a);
// 10

// console.log(b);
// ReferenceError

// console.log(c);
// ReferenceError
⚠

Best practice: Prefer const by default, use let when reassignment is required, and avoid var in modern JavaScript unless you have a specific reason to use its function-scoped behavior.

06

Learn by doing

Common scope examples

Example 01

Nested scopes

A nested scope can access variables declared in its surrounding scope.

JavaScript 
const name = "Amit";

function greet() {

    const message = "Hello";

    if (true) {

        console.log(message);
        console.log(name);

    }

}

greet();

// Hello
// Amit
Example 02

Variable shadowing

A variable declared in an inner scope can have the same name as a variable in an outer scope. The inner variable then shadows the outer variable within that scope.

JavaScript 
const name = "Amit";

function greet() {

    const name = "Rahul";

    console.log(name);

}

greet();

// Rahul

console.log(name);

// Amit
Example 03

Scope inside a loop

Variables declared with let inside a loop remain scoped to the loop block.

JavaScript 
for (let i = 0; i < 3; i++) {

    console.log(i);

}

// console.log(i);
// ReferenceError

Practical JavaScript

Real-life use case

Application Development

Keep private data inside a function

Scope allows application code to keep temporary or implementation-specific values private instead of exposing them unnecessarily to the rest of the program.

JavaScript 
function createOrder(price, quantity) {

    const subtotal = price * quantity;

    const tax = subtotal * 0.18;

    const total = subtotal + tax;

    return total;
}

const orderTotal = createOrder(1000, 2);

console.log("Order Total:", orderTotal);

// Order Total: 2360

// subtotal, tax and total are not
// directly accessible here.
💡

Why this matters: Scope helps you prevent accidental changes to internal variables and makes functions easier to understand, maintain and reuse.

08

Interview preparation

Top 5 interview questions

01 What is scope in JavaScript? +

Scope defines where variables and functions can be accessed in a JavaScript program. Common scope types include global, function, block and module scope.

02 What is the difference between function scope and block scope? +

Function scope means a variable is accessible throughout the function. Block scope limits a variable to a specific block such as an if statement or loop. 

function example() {

    var functionScoped = 10;

    if (true) {

        let blockScoped = 20;

        console.log(functionScoped);
        console.log(blockScoped);

    }

    // blockScoped is unavailable here
}
03 What is lexical scope? +

Lexical scope means variable accessibility is determined by where code is physically written. Inner functions can access variables from their surrounding lexical scopes. 

const outer = "Outer";

function parent() {

    function child() {

        console.log(outer);

    }

    child();

}

parent();

// Outer
04 What is variable shadowing? +

Variable shadowing occurs when a variable declared in an inner scope has the same name as a variable declared in an outer scope. 

let value = 10;

function example() {

    let value = 20;

    console.log(value);

}

example();
// 20

console.log(value);
// 10
05 Why are let and const preferred over var? +

let and const are block-scoped, which generally makes variable behavior easier to reason about. They also have temporal dead zone semantics and cannot be redeclared in the same lexical scope. 

if (true) {

    let count = 10;

    const name = "Amit";

}

// count and name are unavailable here.
