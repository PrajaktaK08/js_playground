01

Foundation

What are data types?

?

What?

A data type defines the kind of value stored or represented by a JavaScript expression.

⏱

When?

Data types matter whenever your program works with values such as numbers, text, objects, arrays, booleans or empty values.

💡

Why?

JavaScript needs to know what kind of value it is working with so operations can behave correctly.

⚙

How?

JavaScript is dynamically typed, so a variable does not have to be permanently associated with one data type.

02

Core classification

JavaScript data types

01

String

Represents textual data. 

const name = "Rahul";
02

Number

Represents numeric values, including integers and floating-point numbers. 

const age = 25;
const price = 99.99;
03

BigInt

Represents integers larger than the safe range of the Number type. 

const bigNumber = 9007199254740993n;
04

Boolean

Represents a logical value: true or false. 

const isLoggedIn = true;
05

Undefined

Represents a variable that has been declared but has not been assigned a value. 

let result;

console.log(result);
06

Null

Represents an intentional absence of a value. 

const selectedUser = null;
07

Symbol

Creates unique primitive values, commonly useful as unique object property keys. 

const id = Symbol("id");
08

Object

Represents collections of related data and functionality. 

const user = {
    name: "Rahul",
    age: 25
};
📌

JavaScript data types are commonly divided into primitive and non-primitive values.

03

Important distinction

Primitive vs non-primitive

Feature Primitive Non-Primitive
Examples String, Number, Boolean, BigInt, Symbol, Undefined, Null Object, Array, Function
Mutable No Yes
Stores Individual value Collections / references
Compared by Value Reference
JavaScript 
let a = 10;
let b = 10;

console.log(a === b); // true


const user1 = {
    name: "Rahul"
};

const user2 = {
    name: "Rahul"
};

console.log(user1 === user2); // false
04

Working with types

Checking data types

JavaScript 
typeof value;
Example 
const name = "Rahul";
const age = 25;
const active = true;

console.log(typeof name);
console.log(typeof age);
console.log(typeof active);
Important: typeof null returns "object". This is a historical JavaScript behavior and is a common interview question.
05

Learn by doing

Data type examples

Example 01

Primitive values

JavaScript primitive values represent individual pieces of data.

JavaScript 
const name = "Rahul";
const age = 25;
const isStudent = true;
const emptyValue = null;

console.log(typeof name);
console.log(typeof age);
console.log(typeof isStudent);
console.log(typeof emptyValue);
Example 02

Object and array

Objects and arrays can contain multiple values and are reference values.

JavaScript 
const user = {
    name: "Rahul",
    age: 25
};

const skills = [
    "HTML",
    "CSS",
    "JavaScript"
];

console.log(typeof user);
console.log(typeof skills);
Example 03

Function

Functions are callable objects and typeof reports them as "function".

JavaScript 
function greet() {
    return "Hello";
}

console.log(typeof greet);

07

Interview preparation

Top 5 interview questions

01 What are the data types in JavaScript? +

JavaScript has primitive and non-primitive data types.

Primitive types include: String, Number, BigInt, Boolean, Undefined, Null and Symbol.

Objects are non-primitive values. Arrays and functions are also objects with special behavior.

02 Is JavaScript statically typed or dynamically typed? +

JavaScript is dynamically typed. A variable can hold values of different types at different points in the program. 

let value = 10;

value = "Hello";

value = true;
03 What is the difference between null and undefined? +

undefined generally indicates that a value has not been assigned or is unavailable.

null is usually assigned intentionally to represent the absence of an object or value.

04 Why does typeof null return "object"? +

This is a historical behavior of JavaScript. Although null is a primitive, typeof null returns "object". 

console.log(typeof null);

// "object"
05 What is the difference between primitive and reference values? +

Primitive values are immutable individual values. Objects are mutable reference values. 

let a = 10;
let b = a;

b = 20;

console.log(a); // 10
console.log(b); // 20


const user1 = {
    name: "Rahul"
};

const user2 = user1;

user2.name = "Amit";

console.log(user1.name); // Amit
