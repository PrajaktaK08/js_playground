Operators

01

Foundation

What are operators?

?

What?

Operators are special symbols or keywords that perform an operation on one or more values.

⏱

When?

Operators are used whenever we need to calculate, compare, assign, combine or evaluate values.

💡

Why?

Operators allow programs to perform calculations, make decisions and manipulate data.

⚙

How?

JavaScript evaluates an operator together with its operands and produces a result.

Fundamentals

Remember: The values that an operator works with are called operands. Different operators perform different types of operations.
03

Core concepts

Types of operators

Type 01

Arithmetic operators

Used for mathematical calculations.

JavaScript
let a = 10; let b = 3; console.log(a + b); // 13 console.log(a - b); // 7 console.log(a * b); // 30 console.log(a / b); // 3.333... console.log(a % b); // 1 console.log(a ** b); // 1000
Type 02

Assignment operators

Used to assign or update values.

JavaScript
let score = 10; score += 5; score -= 2; score *= 2; console.log(score);
Type 03

Comparison operators

Used to compare values and produce a boolean result.

JavaScript
const age = 25; console.log(age > 18); // true console.log(age === 25); // true console.log(age !== 30); // true console.log(age < 18); // false
Type 04

Logical operators

Used to combine or reverse boolean expressions.

JavaScript
const age = 25; const hasLicense = true; console.log(age >= 18 && hasLicense); console.log(age < 18 || hasLicense); console.log(!hasLicense);
Type 05

Ternary operator

A compact way to choose between two expressions.

JavaScript
const age = 20; const status = age >= 18 ? "Adult" : "Minor"; console.log(status);
Type 06

Modern operators

Modern JavaScript provides operators such as nullish coalescing and optional chaining.

JavaScript
const username = null; const displayName = username ?? "Guest"; console.log(displayName); const user = { profile: { name: "Rahul" } }; console.log(user.profile?.name);

Practical JavaScript

Real-life use case

E-Commerce

Shopping cart calculation

Operators are used throughout shopping applications to calculate totals, apply discounts and determine whether a customer qualifies for special offers.

JavaScript
const price = 2000; const quantity = 3; const subtotal = price * quantity; const discount = subtotal >= 5000 ? 500 : 0; const total = subtotal - discount; console.log("Subtotal:", subtotal); console.log("Discount:", discount); console.log("Total:", total);
💡

Interview tip: When comparing values, prefer strict equality === over loose equality == unless you intentionally want type coercion.

06

Interview preparation

Top 5 interview questions

01 What is the difference between == and ===? +

== performs loose equality and may convert types before comparing. === performs strict equality and checks both value and type. 

5 == "5"; // true 5 === "5"; // false
02 What is the difference between && and ||? +

&& evaluates to the first falsy value or the last value when all values are truthy. || evaluates to the first truthy value or the last value when all values are falsy. 

console.log(true && "Hello"); // Hello console.log(false || "Guest"); // Guest
03 What is the difference between ++x and x++? +

++x increments the value before the expression is evaluated. x++ increments it after the current expression is evaluated. 

let x = 5; console.log(++x); // 6 let y = 5; console.log(y++); // 5 console.log(y); // 6
04 What does the ternary operator do? +

The ternary operator provides a compact way to choose between two expressions based on a condition. 

const age = 20; const result = age >= 18 ? "Adult" : "Minor";
05 What is the difference between || and ??? +

|| falls back for any falsy value, while ?? falls back only when the value is null or undefined. 

const count = 0; console.log(count || 10); // 10 console.log(count ?? 10); // 0
