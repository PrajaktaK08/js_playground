Variables

01

Foundation

What are variables?

?

What?

A variable is a named binding that allows a JavaScript program to store and access a value.

⏱

When?

Use variables whenever your program needs to remember information and use that information later.

💡

Why?

Variables make values reusable, readable and easier to update without repeating the same data throughout your program.

⚙

How?

JavaScript creates a binding when you declare a variable and associates that binding with a value.

02

Fundamentals

Syntax

JavaScript 
var variableName = value; 
let variableName = value; 
const variableName = value;
Modern recommendation: Prefer const by default. Use let when reassignment is required. Avoid var in modern code unless you specifically need its behavior.
03

Learn by doing

Simple examples

Example 01

Declaring a variable

A variable can store information that your program can access later.

JavaScript 
let username = "Rahul"; console.log(username);
Example 02

Reassigning a variable

A let variable can be assigned a new value after its declaration.

JavaScript 
let age = 25; age = 30; console.log(age);
Example 03

Using const

Use const when the variable binding should not be reassigned.

JavaScript 
const country = "India"; console.log(country);

Practical JavaScript

Real-life use case

E-Commerce

Shopping cart

Imagine an online shopping application. Product information may remain constant while the quantity in the cart can change.

JavaScript 
const productName = "Laptop"; 
const price = 75000; 
let quantity = 1; 
quantity = 2; 
const total = price * quantity; 
console.log(productName); 
console.log("Quantity:", quantity); 
console.log("Total:", total);
💡

Think about intent. If a value should not be reassigned, use const. If it needs to change, use let.

06

Interview preparation

Top 5 interview questions

01 What is the difference between var, let and const? +

The main differences are scope, reassignment, redeclaration and how they behave during initialization.

  • var is function-scoped.
  • let is block-scoped.
  • const is block-scoped.
  • var can be redeclared.
  • let and const cannot be redeclared in the same scope.
  • const cannot be reassigned.
02 Can a const object be modified? +

Yes. const prevents reassignment of the variable binding, but it does not make an object immutable. 

const user = { name: "Rahul" }; user.name = "Amit"; console.log(user.name);

The object was mutated, but the user binding was not reassigned.

03 What is hoisting with var? +

Function-scoped var declarations are hoisted and initialized with undefined. 

console.log(age); var age = 25;

The output is undefined.

04 What is the Temporal Dead Zone? +

The Temporal Dead Zone, or TDZ, is the period between entering a scope and the point where a let or const variable is initialized. 

console.log(age); 
let age = 25;

Accessing age before initialization causes a ReferenceError.

05 What is the difference between block scope and function scope? +

Function-scoped variables are accessible throughout their function, while block-scoped variables are limited to the block where they are declared. 

function example() { 
if (true) { 
    var a = 10; let b = 20; 
    } 
console.log(a); // 10 
console.log(b); // ReferenceError 
    }
