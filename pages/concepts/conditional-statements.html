Conditional Statements

Learn how JavaScript makes decisions using if, else, else if, switch and the ternary operator.

01

Foundation

What are conditional statements?

?

What?

Conditional statements allow JavaScript to execute different code depending on whether a condition is true or false.

⏱

When?

Use conditions whenever your program needs to make a decision based on data or a situation.

💡

Why?

Applications constantly make decisions such as whether a user is logged in, whether payment succeeded or whether an age requirement is met.

⚙

How?

JavaScript evaluates a condition. If the result is truthy, the associated block of code executes.

02

Fundamentals

Syntax

JavaScript
if (condition) { // code runs when condition is true } if (condition) { // true } else { // false } if (condition1) { // first condition } else if (condition2) { // second condition } else { // none matched }
03

Core concepts

Types of conditional statements

Type 01

if statement

Executes code only when a condition is truthy.

JavaScript
const age = 20; if (age >= 18) { console.log("You are an adult."); }
Type 02

if...else

Chooses between two possible execution paths.

JavaScript
const age = 16; if (age >= 18) { console.log("Adult"); } else { console.log("Minor"); }
Type 03

else if

Checks multiple conditions in sequence.

JavaScript
const marks = 82; if (marks >= 90) { console.log("A+"); } else if (marks >= 75) { console.log("A"); } else if (marks >= 60) { console.log("B"); } else { console.log("Needs improvement"); }
Type 04

Nested conditions

A condition can exist inside another condition.

JavaScript
const isLoggedIn = true; const isAdmin = true; if (isLoggedIn) { if (isAdmin) { console.log("Admin dashboard"); } }
Type 05

switch statement

Useful when one value needs to be compared against several possible cases.

JavaScript
const day = "Monday"; switch (day) { case "Monday": console.log("Start of the week"); break; case "Friday": console.log("Weekend is near"); break; default: console.log("Regular day"); }
Type 06

Ternary operator

Best suited for short two-way decisions that produce a value.

JavaScript
const age = 20; const message = age >= 18 ? "Allowed" : "Not allowed"; console.log(message);

Practical JavaScript

Real-life use case

Authentication

User access control

Websites use conditions to decide what users are allowed to access based on login status and permissions.

JavaScript
const isLoggedIn = true; const role = "admin"; if (!isLoggedIn) { console.log("Please log in."); } else if (role === "admin") { console.log("Open admin dashboard."); } else { console.log("Open user dashboard."); }
💡

Think in decisions. Whenever your application needs to answer a question such as "Is the user logged in?" or "Is the payment successful?", you probably need conditional logic.

06

Interview preparation

Top 5 interview questions

01 What is the difference between if...else and switch? +

if...else is flexible and works well with ranges and complex conditions. A switch is useful when comparing one expression against multiple discrete values.

02 What are truthy and falsy values? +

JavaScript converts values to boolean context when evaluating conditions. Values such as false, 0, "", null, undefined and NaN are falsy. Most other values are truthy. 

if ("Hello") { console.log("Truthy"); } if (0) { console.log("This will not run"); }
03 What happens if break is omitted in switch? +

Without break, execution continues into the following cases. This behavior is called fall-through. 

const value = 1; switch (value) { case 1: console.log("One"); case 2: console.log("Two"); }

Both messages can be printed because the first case does not stop execution.

04 When should you use the ternary operator? +

Use the ternary operator for short and readable two-way decisions that produce a value. Avoid deeply nested ternaries because they can reduce readability. 

const age = 20; const status = age >= 18 ? "Adult" : "Minor";
05 What is the difference between nested conditions and else if? +

An else if chain checks alternative conditions at the same decision level. Nested conditions place one decision inside another and are useful when the second decision depends on the first.
