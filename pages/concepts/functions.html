01

Foundation

What are functions?

?

What?

A function is a reusable block of code designed to perform a specific task. A function can receive input, execute logic and optionally return a result.

⏱

When?

Use a function whenever a piece of logic needs to be reused, organized or separated into a specific task.

💡

Why?

Functions reduce code duplication, improve readability, make code easier to test and divide large programs into smaller manageable pieces.

⚙

How?

Define a function, provide parameters if required, write the required logic and call the function whenever you need that logic.

02

Fundamentals

Function syntax

JavaScript 
function functionName(parameters) {

    // code to execute

    return value;
}


functionName(arguments);
Remember: Defining a function does not execute it. The function runs when it is called.
03

Core concepts

Types of functions

Type 01

Function Declaration

A function declaration defines a named function using the function keyword.

JavaScript 
function greet() {

    console.log("Hello JavaScript!");

}

greet();

// Hello JavaScript!
Type 02

Function Expression

A function can be assigned to a variable. This is called a function expression.

JavaScript 
const greet = function () {

    console.log("Hello!");

};

greet();
Type 03

Arrow Function

Arrow functions provide a shorter syntax for writing functions and have important differences in how this works.

JavaScript 
const add = (a, b) => {

    return a + b;

};

console.log(add(10, 20));
// 30
Type 04

Arrow Function with Implicit Return

If an arrow function contains only one expression, the value can be returned without using return.

JavaScript 
const multiply = (a, b) => a * b;

console.log(multiply(5, 4));
// 20
Type 05

Anonymous Function

An anonymous function is a function without its own function name. It is commonly used as a callback.

JavaScript 
setTimeout(function () {

    console.log("Executed later");

}, 1000);
Type 06

Callback Function

A callback is a function passed to another function as an argument so that it can be executed later or at a specific point.

JavaScript 
function processUser(name, callback) {

    console.log("User:", name);

    callback();

}

processUser("Amit", function () {

    console.log("Processing completed");

});
04

Function inputs

Parameters and arguments

Concept 01

Parameters

Parameters are variables defined in the function declaration. They represent the input that a function expects.

JavaScript 
function greet(name) {

    console.log("Hello", name);

}
Concept 02

Arguments

Arguments are the actual values passed to a function when the function is called.

JavaScript 
function greet(name) {

    console.log("Hello", name);

}

greet("Prajakta");
Concept 03

Default Parameters

A default parameter provides a fallback value when no argument or an undefined value is passed.

JavaScript 
function greet(name = "Guest") {

    console.log(`Hello, ${name}`);

}

greet();
// Hello, Guest

greet("Amit");
// Hello, Amit
Concept 04

Rest Parameters

Rest parameters allow a function to accept any number of arguments and collect them into an array.

JavaScript 
function calculateSum(...numbers) {

    let total = 0;

    for (const number of numbers) {
        total += number;
    }

    return total;
}

console.log(calculateSum(10, 20, 30));
// 60
05

Function output

Return statement

JavaScript 
function add(a, b) {

    return a + b;

}

const result = add(10, 20);

console.log(result);
// 30
💡

Important: When JavaScript reaches a return statement, the function immediately stops executing and sends the returned value back to the caller.

Learn by doing

Common function examples

Example 01

Create a calculator function

Functions are useful for separating individual operations into reusable pieces.

JavaScript 
function add(a, b) {
    return a + b;
}

function subtract(a, b) {
    return a - b;
}

function multiply(a, b) {
    return a * b;
}

console.log(add(10, 5));
// 15

console.log(subtract(10, 5));
// 5

console.log(multiply(10, 5));
// 50
Example 02

Check whether a number is even

A function can encapsulate a condition and return a boolean result.

JavaScript 
function isEven(number) {

    return number % 2 === 0;

}

console.log(isEven(10));
// true

console.log(isEven(7));
// false
Example 03

Calculate factorial

Functions can combine loops and calculations to solve reusable problems.

JavaScript 
function factorial(number) {

    let result = 1;

    for (let i = 1; i <= number; i++) {

        result *= i;

    }

    return result;
}

console.log(factorial(5));
// 120

Practical JavaScript

Real-life use case

E-Commerce

Calculate final product price

An online shopping application can use separate functions for calculating discounts, taxes and the final price.

JavaScript 
function calculateDiscount(price, discount) {

    return price * discount / 100;

}

function calculateTax(price, taxRate) {

    return price * taxRate / 100;

}

function calculateFinalPrice(price, discount, taxRate) {

    const discountAmount =
        calculateDiscount(price, discount);

    const discountedPrice =
        price - discountAmount;

    const tax =
        calculateTax(discountedPrice, taxRate);

    return discountedPrice + tax;
}

const finalPrice =
    calculateFinalPrice(2000, 10, 18);

console.log("Final Price:", finalPrice);
💡

Interview tip: Good functions generally have one clear responsibility. Instead of creating one huge function, divide complex operations into smaller reusable functions.

08

Interview preparation

Top 5 interview questions

01 What is the difference between parameters and arguments? +

Parameters are variables defined in a function declaration. Arguments are the actual values passed to the function when it is called. 

function greet(name) {
    // name is a parameter
}

greet("Amit");
// "Amit" is an argument
02 What is the difference between function declaration and function expression? +

A function declaration creates a named function directly. A function expression creates a function and assigns it to a variable. 

function add(a, b) {
    return a + b;
}


const subtract = function (a, b) {
    return a - b;
};

Function declarations are hoisted with their function body, while function expressions assigned to variables are subject to the initialization rules of those variables.

03 What is an arrow function? +

An arrow function is a shorter function syntax introduced in modern JavaScript. Unlike regular functions, arrow functions do not have their own this, arguments, super or new.target. 

const square = number => number * number;

console.log(square(5));
// 25
04 What happens when a function does not return a value? +

A function that reaches the end without returning a value returns undefined. 

function greet() {

    console.log("Hello");

}

const result = greet();

console.log(result);
// undefined
05 What is a callback function? +

A callback is a function passed to another function as an argument. The receiving function can execute the callback when needed. 

function processData(callback) {

    console.log("Processing...");

    callback();

}

processData(function () {

    console.log("Completed");

});

Create a reusable calculator function

Examples 

calculate(10, 5, "+")
→ 15

calculate(10, 5, "-")
→ 5

calculate(10, 5, "*")
→ 50

calculate(10, 5, "/")
→ 2
Use a switch statement or if...else statements to check the operator and return the appropriate calculation.
