Type Coercion & Conversion

Learn how JavaScript changes values from one type to another, both automatically and explicitly.

Beginner Core JavaScript Interview Essential
Definition Types Conversion Coercion Examples Real Life Interview Challenge
01

Foundation

What is type coercion and conversion?

?

What?

Type conversion means explicitly changing a value from one data type to another. Type coercion means JavaScript automatically converts a value during an operation.

⏱

When?

It occurs whenever values of different types interact or when your program intentionally needs a different representation.

💡

Why?

Understanding conversion and coercion helps you avoid unexpected results and predict JavaScript expressions correctly.

⚙

How?

JavaScript performs implicit coercion in certain operations, while developers can perform explicit conversion using functions such as Number(), String() and Boolean().

02

Core classification

Two ways types can change

01

Explicit conversion

The developer intentionally converts a value to another type. 

const value = "100"; const number = Number(value); console.log(number);
02

Implicit coercion

JavaScript automatically converts a value because an operation requires compatible types. 

const result = "100" - 20; console.log(result);
03

Explicit conversion

Type conversion

String → Number

Number()

Converts a value to a number when possible.

const value = "42"; const result = Number(value); console.log(result); console.log(typeof result);
Number → String

String()

Converts a value to its string representation.

const value = 42; const result = String(value); console.log(result); console.log(typeof result);
Value → Boolean

Boolean()

Converts a value to either true or false. 

console.log(Boolean(1)); console.log(Boolean(0)); console.log(Boolean("hello")); console.log(Boolean(""));
Common conversion syntax 
Number(value); String(value); Boolean(value);
04

Implicit conversion

Type coercion

Example 01

String + Number

With the plus operator, JavaScript can convert the number to a string and concatenate. 

const result = "10" + 5; console.log(result); console.log(typeof result); // "105" // "string"
Example 02

String - Number

The subtraction operator converts numeric strings to numbers when possible. 

const result = "10" - 5; console.log(result); console.log(typeof result); // 5 // "number"
Example 03

Equality coercion

Loose equality can perform type coercion, while strict equality does not perform this coercion. 

console.log(5 == "5"); console.log(5 === "5"); // true // false
⚠️

Prefer === when you want strict equality because it compares both value and type without the coercion performed by loose equality.

Practical JavaScript

Real-life use case

Form Handling

Converting user input

Values retrieved from HTML form controls are commonly strings. Before performing numeric calculations, you often need explicit conversion.

JavaScript 
const quantityInput = "3"; const priceInput = "499"; const quantity = Number(quantityInput); const price = Number(priceInput); const total = quantity * price; console.log("Quantity:", quantity); console.log("Price:", price); console.log("Total:", total);
💡

Form values are commonly strings. Explicitly converting them before calculations makes your intention clear and prevents confusing results.

09

Interview preparation

Top 5 interview questions

01 What is the difference between type conversion and type coercion? +

Type conversion is explicit and controlled by the developer. Type coercion is an automatic conversion performed by JavaScript during certain operations. 

// Explicit conversion Number("10"); // Implicit coercion "10" - 5;
02 What is the output of "5" + 2? +

The result is "52". With the plus operator, when one operand is a string, JavaScript performs string concatenation. 

console.log("5" + 2); // "52"
03 What is the difference between == and ===? +

== performs loose equality comparison and may coerce types. === performs strict equality comparison without that coercion. 

5 == "5"; // true 5 === "5"; // false
04 What are truthy and falsy values? +

A truthy value behaves like true when converted to a boolean. A falsy value behaves like false.

Common falsy values include false, 0, "", null, undefined and NaN.

05 What is the output of "10" - 2 and why? +

The result is 8. The subtraction operator requires numeric operands, so JavaScript converts the string "10" into the number 10. 

console.log("10" - 2); // 8
