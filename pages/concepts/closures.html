Closures

Understand how a function can remember and access variables from its outer lexical scope even after the outer function has finished executing.

Intermediate Functions Interview Essential
Definition Syntax How It Works Examples Real Life Interview Challenge
01

Foundation

What is a closure?

?

What?

A closure is created when a function retains access to variables from its surrounding lexical scope, even when that outer scope is no longer executing.

⏱

When?

Closures are commonly used when functions need to remember state, create private variables, implement callbacks or preserve data between function calls.

💡

Why?

Closures allow developers to preserve state and create controlled access to data without exposing variables globally.

⚙

How?

When an inner function references variables from an outer lexical scope, JavaScript keeps the necessary lexical environment available for that function.

02

Fundamentals

Closure syntax

JavaScript 
function outerFunction() {

    let outerVariable = "Hello";

    function innerFunction() {

        console.log(outerVariable);

    }

    return innerFunction;
}


const result = outerFunction();

result();

// Hello
Remember: The important part is not simply having a nested function. A closure exists when the inner function retains access to variables from its surrounding lexical environment.
03

Core concept

How closures work

Step 01

Outer function creates a variable

The outer function creates a variable inside its local scope. 

function outer() {

    let message = "Hello";

}
Step 02

Inner function accesses it

The nested function references the variable from the surrounding lexical scope. 

function outer() {

    let message = "Hello";

    function inner() {

        console.log(message);

    }

}
Step 03

Return the inner function

The inner function can be returned and called later. It still retains access to the variable it referenced. 

function outer() {

    let message = "Hello";

    function inner() {

        console.log(message);

    }

    return inner;
}

const greet = outer();

greet();

// Hello
💡

Think of a closure as a function carrying a backpack: the function carries references to the outer variables it needs even after the outer function has finished executing.

04

Learn by doing

Common closure examples

Example 01

Private counter

Closures can preserve a private counter that cannot be directly accessed from outside the function.

JavaScript 
function createCounter() {

    let count = 0;

    return function () {

        count++;

        return count;

    };
}

const counter = createCounter();

console.log(counter());
// 1

console.log(counter());
// 2

console.log(counter());
// 3
Example 02

Independent closure state

Each call to the outer function creates a separate lexical environment, so different closures can maintain independent state.

JavaScript 
function createCounter() {

    let count = 0;

    return function () {

        count++;

        return count;

    };
}

const counterA = createCounter();
const counterB = createCounter();

console.log(counterA());
// 1

console.log(counterA());
// 2

console.log(counterB());
// 1
Example 03

Function factory

A function can create other functions with customized behavior using closures.

JavaScript 
function createMultiplier(multiplier) {

    return function (number) {

        return number * multiplier;

    };

}

const double = createMultiplier(2);
const triple = createMultiplier(3);

console.log(double(5));
// 10

console.log(triple(5));
// 15
Example 04

Closures with callbacks

Callback functions often form closures because they can retain access to variables from the scope where they were created.

JavaScript 
function greetLater(name) {

    setTimeout(function () {

        console.log(`Hello, ${name}`);

    }, 1000);

}

greetLater("Amit");

05

Important use

Closures and data privacy

Private State

Hide implementation details

Closures can keep internal variables inaccessible directly from outside code while exposing only the operations that should be allowed.

JavaScript 
function createBankAccount(initialBalance) {

    let balance = initialBalance;

    return {

        deposit(amount) {

            balance += amount;

        },

        getBalance() {

            return balance;

        }

    };

}

const account = createBankAccount(1000);

account.deposit(500);

console.log(account.getBalance());
// 1500

// Direct access to balance is unavailable:
// account.balance
// undefined
💡

Important: Closures are not the only way to create private state in modern JavaScript. JavaScript also provides private class fields using the # syntax. Closures remain important because they are fundamental to lexical scoping and functional patterns.

06

Practical JavaScript

Real-life use case

User Interface

Create a reusable notification function

A closure can remember configuration such as a notification type while exposing a simple function that displays messages.

JavaScript 
function createNotifier(type) {

    return function (message) {

        console.log(`[${type}] ${message}`);

    };

}

const successNotifier =
    createNotifier("SUCCESS");

const errorNotifier =
    createNotifier("ERROR");

successNotifier("Profile updated");
// [SUCCESS] Profile updated

errorNotifier("Payment failed");
// [ERROR] Payment failed
🎯

Where you will see closures: event handlers, callbacks, timers, function factories, memoization, private state and many JavaScript frameworks and libraries.

07

Interview preparation

Top 5 interview questions

01 What is a closure in JavaScript? +

A closure is a function together with access to the lexical environment in which that function was created. It allows the function to access variables from its surrounding scope even after that outer execution has finished. 

function outer() {

    const message = "Hello";

    return function () {

        console.log(message);

    };

}

const greet = outer();

greet();
// Hello
02 Why does a closure remember variables after the outer function finishes? +

The inner function retains a reference to the lexical environment containing the variables it needs. As long as that closure remains reachable, the required environment can remain available.

03 What are practical uses of closures? +

Common uses include private state, function factories, callbacks, event handlers, memoization and preserving state between function calls. 

function createMultiplier(value) {

    return number => number * value;

}

const double = createMultiplier(2);

console.log(double(10));
// 20
04 Can closures cause memory problems? +

A closure itself is not a memory leak. However, unnecessarily keeping closures or references alive can keep otherwise-unused objects reachable for longer than necessary. Good lifecycle management is important for long-running applications.

05 What is the difference between scope and closure? +

Scope determines where variables can be accessed. A closure is the behavior of a function retaining access to variables from its surrounding lexical scope after that surrounding execution has finished. 

function outer() {

    let count = 0;

    return function () {

        count++;

        return count;

    };

}

const counter = outer();

console.log(counter());
// 1
