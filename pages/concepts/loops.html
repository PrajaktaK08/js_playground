01

Foundation

What are loops?

?

What?

A loop is a control-flow structure that repeatedly executes a block of code while a condition is satisfied or while there are values to iterate over.

⏱

When?

Use loops when the same operation needs to be performed multiple times, especially when working with arrays, objects or repeated calculations.

💡

Why?

Loops prevent duplicate code and make it possible to process large amounts of data efficiently.

⚙

How?

JavaScript repeatedly executes the loop body according to a condition, counter, iterator or collection until the loop should stop.

02

Fundamentals

Loop syntax

JavaScript 
for (initialization; condition; update) {
    // code to execute
}


while (condition) {
    // code to execute
}


do {
    // code to execute
} while (condition);


for (const value of iterable) {
    // code to execute
}


for (const key in object) {
    // code to execute
}
Remember: A loop needs a clear stopping condition. If the condition never becomes false, the loop can become an infinite loop.
03

Core concepts

Types of loops

Type 01

for loop

The traditional for loop is useful when you know how many times you want to execute the code.

JavaScript 
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

// Output:
// 1
// 2
// 3
// 4
// 5
Type 02

while loop

A while loop continues running as long as its condition remains true.

JavaScript 
let count = 1;

while (count <= 5) {

    console.log(count);

    count++;
}
Type 03

do...while loop

A do...while loop executes its body at least once before checking the condition.

JavaScript 
let number = 1;

do {

    console.log(number);

    number++;

} while (number <= 5);
Type 04

for...of loop

Used to iterate over the values of iterable objects such as arrays, strings, maps and sets.

JavaScript 
const fruits = [
    "Apple",
    "Banana",
    "Mango"
];

for (const fruit of fruits) {

    console.log(fruit);

}
Type 05

for...in loop

Used to iterate over enumerable property keys of an object.

JavaScript 
const user = {
    name: "Amit",
    age: 25,
    city: "Delhi"
};

for (const key in user) {

    console.log(key, user[key]);

}
Type 06

Nested loops

A loop inside another loop is called a nested loop. It is commonly used for grids, matrices and combinations.

JavaScript 
for (let row = 1; row <= 3; row++) {

    for (let column = 1; column <= 3; column++) {

        console.log(
            `Row ${row}, Column ${column}`
        );

    }

}
Type 07

break and continue

break completely stops a loop, while continue skips the current iteration and moves to the next one.

JavaScript 
for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}

// 1
// 2
// 4
// 5


for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        break;
    }

    console.log(i);
}

// 1
// 2
04

Learn by doing

Common loop examples

Example 01

Calculate the sum

Use a loop to calculate the total of all numbers in an array.

JavaScript 
const numbers = [10, 20, 30, 40];

let sum = 0;

for (const number of numbers) {

    sum += number;

}

console.log(sum);
// 100
Example 02

Find the largest number

A loop can compare every value and keep track of the largest value found so far.

JavaScript 
const numbers = [12, 45, 7, 89, 23];

let largest = numbers[0];

for (const number of numbers) {

    if (number > largest) {
        largest = number;
    }

}

console.log(largest);
// 89
Example 03

Reverse a string

A loop can process a string character by character and build a reversed string.

JavaScript 
const text = "JavaScript";

let reversed = "";

for (let i = text.length - 1; i >= 0; i--) {

    reversed += text[i];

}

console.log(reversed);
// tpircSavaJ

Practical JavaScript

Real-life use case

E-Commerce

Calculate shopping cart total

Shopping applications commonly loop through cart items to calculate the subtotal, apply discounts and prepare the final amount.

JavaScript 
const cart = [
    {
        name: "Keyboard",
        price: 1500,
        quantity: 2
    },
    {
        name: "Mouse",
        price: 800,
        quantity: 1
    },
    {
        name: "Headphones",
        price: 2000,
        quantity: 1
    }
];

let total = 0;

for (const item of cart) {

    total += item.price * item.quantity;

}

console.log("Cart Total:", total);
💡

Interview tip: Choose the loop based on the problem. Use for...of when you need values from an iterable, for...in for object keys, and a traditional for loop when you need precise control over the index or iteration count.

06

Interview preparation

Top 5 interview questions

01 What is the difference between for, while and do...while? +

A for loop is commonly used when the number of iterations or counter logic is known. A while loop is useful when repetition depends mainly on a condition. A do...while loop always executes its body at least once before checking the condition.

02 What is the difference between for...of and for...in? +

for...of iterates over values of an iterable, while for...in iterates over enumerable property keys. 

const fruits = ["Apple", "Mango"];

for (const fruit of fruits) {
    console.log(fruit);
}


const user = {
    name: "Amit",
    age: 25
};

for (const key in user) {
    console.log(key);
}
03 What is an infinite loop and how can you avoid it? +

An infinite loop occurs when the loop's stopping condition never becomes false. Make sure the loop variable or condition changes appropriately. 

let count = 0;

while (count < 5) {

    console.log(count);

    count++;
}

Here, count++ eventually makes the condition false.

04 What is the difference between break and continue? +

break immediately terminates the loop. continue skips the rest of the current iteration and moves to the next iteration. 

for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}

// 1
// 2
// 4
// 5
05 Why should for...in generally not be used for arrays? +

for...in is designed for enumerable property keys, not specifically for array values. For arrays, for...of is usually clearer when you need the values. 

const numbers = [10, 20, 30];

for (const number of numbers) {

    console.log(number);

}

// 10
// 20
// 30
